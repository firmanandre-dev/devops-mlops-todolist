# Todo List App

## Deskripsi
Aplikasi todolist sederhana untuk mencatat, mengelola, dan menandai tugas harian. Project ini juga menjadi workspace pembelajaran DevOps & MLOps sepanjang semester.

## Tujuan Project
Membuat aplikasi todolist sederhana sebagai bahan latihan alur DevOps: version control, CI/CD, containerisasi, dan deployment.

## Fitur Awal
- Menambah tugas
- Melihat daftar tugas
- Mengedit tugas
- Menandai tugas selesai
- Menghapus tugas

## Technology Stack
- Backend: PHP (Laravel)
- Frontend: HTML, CSS, JavaScript (Blade, Bootstrap)
- Database: MySQL
- Scripting & MLOps: Python
- Testing: PHPUnit
- Web Server: Nginx
- DevOps: Git, GitHub, Docker, GitHub Actions
